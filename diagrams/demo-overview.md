# Setup overview: diagram notes

Diagram: `demo-overview.drawio`, generated by `gen_overview.py` and exported as `demo-overview.png` with
`drawio -x -f png -s 2 -o demo-overview.png demo-overview.drawio`.

## Demo flow, the numbered arrows
1. base-watch reads the latest `hi/python:3.11` digest from the Red Hat Hardened Images registry.
2. A newer digest is committed to `cve-demo/app`, the base image pinned in the Containerfile.
3. The Gitea push webhook calls the EventListener, which starts `build-and-stage`.
4. buildah rebuilds on the new base and pushes the image to Red Hat Quay.
5. Tekton Chains signs keyless: Fulcio issues a 10-minute certificate for the Keycloak identity
   `chains@cve-demo.local`, using the token from the refresher. Signature and SLSA provenance are stored
   in Quay as `.sig` and `.att` and recorded in Rekor.
6. Three checks run in parallel: the ACS scan gate, which allows no fixable Important or Critical CVE;
   Conforma, which verifies the keyless signatures against the TUF trust root and checks that the
   provenance comes from this pipeline and the Red Hat build task; and Red Hat's SBOM of the exact base
   image, uploaded to Trusted Profile Analyzer.
7. gitops-promote updates the stage overlay and opens the prod pull request with three lines of
   evidence: ACS, Conforma, SBOM.
8. Argo CD syncs stage.
9. The approver merges the pull request into the protected prod branch; Argo CD syncs prod.
10. The ACS admission controller admits only images signed by the pipeline: Fulcio identity and Rekor.

## Supporting data, the dashed arrows
- Identity and trust: realm `tas-chains` feeds the token refresher, which feeds Chains. Fulcio trusts the
  realm as issuer. ACS checks signatures online against Rekor. Conforma verifies against the TUF trust root.
- Vulnerability data: Red Hat security data feeds ACS Scanner V4 and, as VEX, the TPA importer, filtered
  to the CVEs found in the scanned images.
- Red Hat's SBOM for each Hardened Images digest is fetched by the `sbom-upload` task.
- Storage: Quay images and TPA documents live in NooBaa buckets, the standalone Multicloud Object Gateway
  of OpenShift Data Foundation.
- ACS Sensor pulls images from Quay for delegated scanning with the read-only robot.
